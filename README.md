# adriangalilea/homebrew-tap

Homebrew recipes for my apps.

```
brew install --cask adriangalilea/tap/awake
```

| Cask | |
|---|---|
| [awake](https://github.com/adriangalilea/awake) | Keep a Mac awake, lid closed included |

Recipes here are generated, not hand-edited: each project's `make release` rewrites its version and sha256 after publishing the notarized dmg.
